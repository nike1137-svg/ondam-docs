## 할 수 있는 일

### 생활 정보
- **날씨·미세먼지** — 오늘, 이번 주, 다음 주 날씨를 물어보면 알려줍니다
- **버스 도착 정보** — 정류장에 언제 버스가 오는지 확인합니다
- **약국 안내** — 가까운 약국과 문 여는 시간을 찾아줍니다
- **뉴스** — 그날의 소식을 간추려 전해줍니다
- **건강 관련 질문** — 궁금한 점을 물어보면 이해하기 쉽게 설명합니다

### 기억하고 알려주기
- **기념일 기억** — 생신, 결혼기념일 같은 날짜를 말해두면 잊지 않고 알려줍니다
- **알람과 약속** — "내일 10시에 병원" 처럼 말하면 저장했다가 때맞춰 알려줍니다

### 편하게 주고받기
- **음성으로 답하기** — 글씨가 잘 안 보여도 괜찮도록, 답변을 음성으로도 들려줍니다
- **음성으로 묻기** — 타자를 치지 않고 말로 물어볼 수 있습니다
- **사진 보고 답하기** — 약봉투나 안내문을 찍어 보내면 읽고 설명해줍니다
- **버튼으로 고르기** — 무엇을 물어야 할지 막막할 때, 버튼과 추천 질문으로 안내합니다

### 대화
- **말동무** — 앞뒤 이야기를 기억하며 자연스럽게 대화를 이어갑니다
- **가족 단체방** — 가족 단체방에 초대해 함께 쓸 수 있습니다

### 긴급도움
- **긴급도움** — 긴급도움 버튼을 누르면 즉시 보호자에게 메세지가 전송되고 현위치전및 119 연락을 진행합니다.

> 버튼 메뉴는 LINE 정책상 1:1 대화에서만 표시됩니다. 단체방에서는 "온담아"라고 부른 뒤 말씀하시면 됩니다.
